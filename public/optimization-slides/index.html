02 / WORKSPACE

探索路徑由單一清單，升級為個人化工作台。

入口更完整

  • 搜尋 skill、關鍵字、場景與技術標籤。
  • 分類、全部案例、我的收藏與最近瀏覽可互相切換。
  • 案例詳細 modal 提供情境、實作重點、先備條件、預期成果與啟用指令。

狀態更可靠

  • 收藏與比較狀態以安全方式保存，並限制最多三個比較案例。
  • 開啟詳細頁會產生 query deep link，方便回訪與分享。
  • Escape、焦點回復與 scroll lock 讓 modal 操作可預期。

05 / ACCESSIBILITY

可及性不是裝飾，而是狀態設計。

鍵盤可用

加入全站 focus-visible、modal Escape 關閉、開啟後焦點安排與關閉後焦點回復，降低鍵盤使用者迷失的機率。

語意可讀

搜尋結果與比較上限使用 live region；分類、收藏、比較模式以 aria-pressed 表達目前狀態。

動態可控

加入 prefers-reduced-motion 規則，並讓手機版的 filter、view switch、排序選單在窄螢幕自然堆疊。
