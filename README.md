# Junbin Kuo · NVIDIA AI Portfolio

Portfolio site for NVIDIA AI application, Physical AI, GPU analytics, and
product-system case studies. Live at <https://jjfishjj.github.io/>.

## Public Hugging Face evidence

- [Isaac Sim-to-Real VLA Lab](https://huggingface.co/spaces/junbin666/isaac-sim2real-vla-lab) — interactive Physical AI validation workflow with explicit mock, remote RTX, and hardware safety boundaries.
- [Tiny Vial CNN v2](https://huggingface.co/junbin666/tiny-vial-cnn-sdg-objectness-v2) — 141k-parameter objectness/localization baseline; 0/100 false positives on a held-out synthetic hard-negative suite, with an approximate 3% rule-of-three 95% FPR upper bound.
- [NIM RAG Language Tutor](https://huggingface.co/spaces/junbin666/nim-rag-language-tutor) — grounded bilingual tutoring workflow with visible retrieval evidence and abstention.

These are portfolio prototypes, not production or real-world robustness claims.
